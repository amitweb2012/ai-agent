# Roadmap

Phase 1 — Foundations
- OpenAI-compatible model integration
- Deterministic tools
- Tool routing
- Embeddings and cosine similarity
- Basic RAG
- MCP server/client

Phase 2 — Agent engineering
- Structured function/tool calling
- Tool argument validation
- Multi-step tool loops
- Conversation memory
- Streaming
- Retry and timeout policies

Phase 3 — Enterprise RAG
- Document ingestion
- Chunking and metadata
- PostgreSQL + pgvector
- Hybrid retrieval and reranking
- Citations
- RAG evaluation

Phase 4 — Production
- FastAPI service
- Redis
- OpenTelemetry
- Prometheus/Grafana
- OAuth2/OIDC/JWT/RBAC
- Docker hardening
- Kubernetes/Helm
- AWS EKS / Azure AKS
